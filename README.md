# 📄 Document Q&A RAG Assistant

## 📌 Project Overview
This project is a **Retrieval-Augmented Generation (RAG) based Document Question Answering system**.  
It allows users to upload documents and ask natural language questions, generating accurate answers by retrieving relevant context from the documents and using a Large Language Model.

---

## ✨ Key Features
- Upload and process text-based documents (PDF / TXT)
- Text chunking for efficient document indexing
- Vector embedding generation for semantic search
- Similarity-based document retrieval
- Retrieval-Augmented Generation (RAG) pipeline
- Context-aware answers generated using an LLM
- Reduces hallucinations by grounding responses in documents
- Scalable architecture for large documents
- User-friendly question-answering workflow

---

## 🧠 How It Works (RAG Flow)
1. Document is loaded and split into chunks  
2. Chunks are converted into vector embeddings  
3. User query is embedded and matched using similarity search  
4. Relevant document chunks are retrieved  
5. LLM generates an answer using retrieved context
